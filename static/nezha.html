三种数据接入方式
标准化接入，灵活对接公安网现有业务系统
🔌

数据库直连

优势：延迟最低、最及时

对已建成的业务数据库直接读取，秒级返回。

典型：监控抓拍库 → 小案快破
民警发出指令秒级响应

🔗

API 接口对接

优势：低侵入性

标准 HTTP/HTTPS 协议对接，不需改动源系统数据库。

典型：轨迹系统 · 地址标准化
地图服务 · 提供文档即集成

📁

数据文件同步

优势：兼容性最强

CSV/Excel/JSON 批量同步，对方系统零改造。

典型：摄像头点位库 → 轨迹哨兵
全市点位按周期同步

接入管理：所有通道统一注册到授权中心，管理调用频率、访问权限和健康状态。任一通道异常自动告警。

第四章 · 智能体应用
为什么基层警务需要智能体？
信息化 → 智慧化：从多系统切换到一个入口对话
💬

降低技术使用门槛

信息化时代：民警在 PGIS、监控平台、轨迹系统、警综平台等多个系统间来回切换，学习成本高、操作路径长。

AI时代：自然语言对话，AI 自动理解意图并调度底层能力，零门槛上手。

🧠

经验沉淀与全员共享

信息化时代：优秀民警的研判经验、分析思路停留在个人脑中，难以传递和复用。

AI时代：Skills 机制将业务实战技能封装固化，新民警也能调用老民警的"脑子"，实现全员共享。

⚡

AI 提效

信息化时代：民警手工跨多系统查询数据、人工比对分析，一个研判任务动辄数小时。

AI时代：AI 自动编排工具链，一次对话串联 5~6 个工具，从指令到结果缩减至分钟级。

📋

政策驱动

AI时代：公安十五五规划明确"新一代信息技术与公安业务深度融合，构建数据驱动的警务新模式"，智能体正是将 AI 能力与公安业务场景深度绑定的核心载体。

第四章 · 智能体应用
小案快破智能体
盗窃 / 寻衅——小案不小看

🎯 场景定位

侵财类、暴力寻衅类"小案件"——嫌疑人有前科/劣迹比例远高于其他案件，出狱后极易再犯。

⚠️ 解决什么

派出所民警接到小案要自己串线索，案子多串不过来，群众满意度低。

👥 目标用户

派出所值班民警：接警后第一时间调取周边监控
刑侦办案民警：快速锁定嫌疑人轨迹
案件研判人员：串并分析高频作案

警情进来 → 地址标准化 → 500 米圈选 → 时空碰撞 → 高频目标标红

现状小案快破
民警登录视频监控平台，手动调取案发地周边多个摄像头画面，逐段回放查看输入三要素，自动查询
凭经验判断抓拍记录与案件的关联，跨系统筛选效率低1000米自动搜索，按人聚合
分析结果需在多个系统间来回切换核对，效率低易遗漏按人分层上图，自动标注
口语化地址需人工补全缺失信息后才能精确定位智能标准化，自动补全
数据核对需人工参与比对，工作量大难以保证准确性内置校验，一票否决

第四章 · 智能体应用
轨迹哨兵智能体
发现隐蔽的时空交集，让尾随和同行关系一目了然

🎯 场景定位

追踪传染病密切接触者、排查犯罪嫌疑人同行关系或活动交集、客群重叠分析等——通过时空碰撞发现隐蔽的人员关联。

⚠️ 解决什么

刑侦民警查嫌疑人有没有同伙、有没有人尾随目标，人工排查看不全还容易漏。

👥 目标用户

刑侦研判民警：验证多名嫌疑人同行关系
反诈/反扒专班：分组监控重点人员
情报分析人员：批量排查时空关联

批量拉取轨迹 → 30min/500m碰撞 → 多人碰撞优先 → 跨组/同伙分析

现状轨迹哨兵
逐人登录轨迹系统调阅轨迹，用Excel记录时间地点，再用工具比对交叉情况Excel 分组文件，自动查询
两人是否"碰面"凭经验判断，缺乏量化标准，容易遗漏严格：≤500m+≤30min
多人分组分析需反复切换查询，工作量随人数成倍增长多分组批量，组内碰撞
分析结果需跨系统整理为文字报告，缺乏空间可视化碰撞点自动上图标注
轨迹数据分散在不同业务系统中，需跨系统串联比对自动串联轨迹+点位库

第六章 · 常见问题
常见问题
部署 / 安全 / 信创 / 开发周期等核心顾虑
1

每个县区都要部署一套？

不需要每个地方部署一套，可以集中部署远程使用。

2

为什么不能每个场景单独建系统？

多个场景共用地址标准化和地图画布。各建各的对接做两遍。哪吒把公共能力做成共享底座，新场景只开发"技能"。

3

怎么管理多单位多环境？

按用户自动创建隔离环境，统一管理版本升级（灰度发布+一键回滚），集中监控运行状态。

4

数据安全和权限如何保障？

平台标准的用户权限和数据使用权限。

5

大模型"幻觉"怎么保证？

确定性任务走的skills工作流保证数据准确，回答有限制最大限度保障不乱说。

6

信创国产化支持？

系统是平台开发的国产都支持。用的组件如数据库可以迁移到项目要求的信创组件。

7

新智能体上线周期？

看需求和数据条件。数据和业务清晰的情况下，需要2-3天，FDE 开发。

8

多智能体并发性能？

会下降，性能取决于模型能力。skills层面做了代码层面资源隔离。

9

已建 PGIS / 雪亮工程等业务系统是不是白建了？哪吒与他们什么关系？

没有白建，其他系统可以作为服务能力给哪吒赋能，哪吒使用对应平台的服务融合到业务。
